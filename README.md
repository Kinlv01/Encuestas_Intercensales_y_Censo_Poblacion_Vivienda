# 🗳️ Encuestas Intercensales y Censo de Poblacion de Vivienda 🌎

A continuación, se documentan y compilan los datos de las encuestas intercensales y del Censo de Población y Vivienda 2020, obtenidos del sitio oficial del INEGI. Esto con el fin de concentrar toda la información en un mismo documento y, asimismo, poder utilizarla más adelante en la identificación y análisis de las variables de interés.

## 🖇️ Objetivo 
 🟡 Sistematización y documentación de fuentes demográficas 
 - Recopilación y revisión de cuestionarios, descriptores y diccionarios de variables del Censo de Población y Vivienda 2020 y la Encuesta Intercensal 2025.
 - Creación de un repositorio estructurado que garantice la optimización metodológica y el respaldo de las fuentes oficiales.
 - Concentración y normalización de la información técnica para facilitar la identificación y el análisis posterior de las variables de interés.

## 🖥️🧠 Material de apoyo
Se hizo uso de:
- 📊 Excel
- 🗺️ INEGI (_base de datos_)
- 📦 R / RStudio (_entorno de programación y ejecución_)
- 📄 Quarto (_documentos dinámicos y visualización_)
